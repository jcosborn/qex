## Hamiltonian Monte Carlo and gradient flow for flavor-degenerate HISQ

This folder contains QEX software for running Hamiltonian Monte Carlo simulations with $N_{\mathrm{f}}=4$ degenerate highly improved staggered fermions, 
Hasenbusch preconditioning, and tree-level improved Symanzik (Luescher-Weiss) gauge action. It also contains software for running and making measurements
of gradient flow observables with arbitrary rectangle flow actions.
